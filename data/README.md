# Data Sources & Ownership

This directory contains data files used by the application for retrieval and assistant responses.

## Files Overview

| File | Source | Owner | Update Frequency | Description |
| :--- | :--- | :--- | :--- | :--- |
| `offices.csv` | University Public Website / Official Portal | Training Office & IT Department | Monthly / As needed | Contains details about university offices, including names, room locations, and operating hours. |

## Notes on Usage

- All data stored in this directory must strictly come from **publicly available sources**.
- Any new data files added to this directory should be documented in this `README.md` file with their respective source, owner, and update frequency.
